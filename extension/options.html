Data Management

All data is stored locally in your browser. Nothing is transmitted to any server. Clearing data is permanent and cannot be undone.

Permissions

  • activeTab — Access the current tab only when you explicitly trigger an action
  • contextMenus — Add the "Inspect with ContextShield" right-click menu item
  • storage — Save settings, notes, and inspection history locally

ContextShield does not request broad host permissions. Analysis runs on-demand when you choose to inspect text or a page.

About

ContextShield v1.0.0 — A browser extension for investigating online claims, discovering missing context, and evaluating evidence. All analysis runs locally using deterministic rules. No remote API, AI service, or account is required.
