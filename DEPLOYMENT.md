# Deployment

- **Hostname:** `contextshield.rushilreddy.dev`
- **Upload:** upload the contents of `dist/` into the Hostinger document root for this subdomain.
- **Build:** `npm run build`
- **Local output:** `dist/`

The browser extension package itself is separate from this marketing/demo site; load the tracked `extension/` directory through the browser's extension developer tools when testing locally.
